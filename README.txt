PUBLISH ON CLOUDFLARE
1. Open Cloudflare.
2. Choose “Upload your static files”.
3. Upload the ZIP file or the contents of this folder.
4. Deploy.
5. Open the generated *.workers.dev address.
6. Add a custom domain in the project settings.
